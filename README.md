# 短剧人格鉴定

《短剧人格鉴定：你的性格能在短剧里活几集？》—— 像素风单文件互动网页。

- 纯静态，无后端、无构建步骤
- 20 道题，男频 / 女频双频道题库，32 套剧本人设
- 结果页支持生成分享图（内置二维码）

## 部署

GitHub Pages 从 `main` 分支根目录发布。更新内容后直接推送 `index.html` 即可，约 1 分钟生效。

`.nojekyll` 用于跳过 Jekyll 构建，避免静态资源被模板引擎处理。

## 自定义域名

在仓库根目录放一个 `CNAME` 文件，内容只有一行你的域名（如 `drama.example.com`），
然后在域名注册商处添加一条 CNAME 记录指向 `<用户名>.github.io`，即可用自有域名访问。
